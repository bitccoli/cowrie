The problem

Every Cashu mint has a keeper.

Cashu gives us private, instant ecash. But each mint is one operator holding one key and one pot of reserves. If the keeper sails off, the shells sail with them.

Federated Cashu shares the key among guardians, so no one can sign alone. But the guardians still have to keep the ledger, and still guard the chest.

How Cowrie works

Guardians sign. The contract keeps the vault.

Cowrie follows Cashu's federated mint design and moves consensus and custody into a Move smart contract on Sui.

A federation signs

Five guardians each hold a share of the key; any four can sign a note, none can sign alone.

  • 4-of-5 threshold BLS12-381
  • Dealer-free Pedersen key generation
  • Guardians sign only what the contract has recorded

A contract keeps the vault

The MintVault Move contract does the jobs a mint operator used to do.

  • Records every spent note, so nothing is spent twice
  • Holds the reserves in plain sight, on-chain
  • Pays out any valid note itself: no one can refuse

Safety when things go wrong

Every signature share is checked before it's used.

  • A forging guardian is caught; the rest keep signing
  • Too many offline and issuance halts safely
  • Even if guardians collude, an hourly limit caps withdrawals

Why it works

A signature anyone can check, even a contract.

A normal Cashu note can only be checked by the mint that signed it. Cowrie's BLS12-381 notes can be verified by anyone, offline, with no extra proof, which is what lets a smart contract pay them out on its own.

48 Bper signature, no DLEQ proof needed
32.6%smaller tokens than secp256k1 + DLEQ
1 txto settle hundreds of streamed notes
1.2 msto verify a note offline

An independent mint

Written from scratch in Rust and Move.

Cowrie is a clean-room implementation of Cashu's federated mint. It speaks the Cashu API, ships its own browser and terminal wallets, and the same binary also runs standalone on Lightning for operators who don't want an on-chain vault.

Run it

Try it in thirty seconds.

Start the mint, open the playground, and make a guardian lie.

# start the 4-of-5 mint, this page and the playground
cargo run -p cowrie-cashu-mintd --bin cowried -- --bind 127.0.0.1:3338 --data-dir ./cowrie-data

# settle against the Move vault on a Sui localnet
./scripts/deploy-sui-localnet.sh

# Rust and Move tests
cargo test --workspace
sui move test --path cashu/move/cowrie_cashu
